# Recibida

Frontend mobile-first para la reserva de entradas de un evento.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Validación

```bash
npm run lint
npm run build
```

El proyecto usa únicamente datos mock locales. No incluye backend, base de datos ni integraciones reales de pagos, email o WhatsApp.
